# 冥想课程 iOS 应用 (Meditation App)

一个类似 Calm 的冥想课程 iOS 应用，使用 SwiftUI 构建。

## 功能特性

### 核心功能
- ✨ **冥想课程库** - 多种分类的引导式冥想课程
- 🎵 **音频播放器** - 流畅的音频播放体验
- ⏱️ **冥想计时器** - 自定义时长的自由冥想
- 📊 **进度统计** - 追踪你的冥想历程
- 🎨 **精美界面** - 平静舒适的视觉设计

### 冥想分类
- 放松解压 (Relaxation)
- 改善睡眠 (Sleep)
- 提升专注 (Focus)
- 缓解焦虑 (Anxiety Relief)
- 正念冥想 (Mindfulness)
- 呼吸练习 (Breathing)

## 技术栈

- SwiftUI - 现代化的 UI 框架
- AVFoundation - 音频播放
- Combine - 响应式编程
- SwiftData/CoreData - 数据持久化

## 项目结构

```
MeditationApp/
├── Models/              # 数据模型
├── Views/               # 视图组件
├── ViewModels/          # 视图模型
├── Services/            # 业务服务
├── Resources/           # 资源文件
└── Utils/               # 工具类
```

## 安装说明

1. 使用 Xcode 14.0 或更高版本
2. 打开 `MeditationApp.xcodeproj`
3. 选择目标设备或模拟器
4. 点击运行

## 最低系统要求

- iOS 16.0+
- Xcode 14.0+
- Swift 5.7+
