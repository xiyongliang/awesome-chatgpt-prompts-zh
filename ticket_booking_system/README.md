# 订票系统

一个功能完整的订票系统，支持用户注册、座位选择、在线支付和票券核销。

## 功能特性

### 1. 用户注册与登录
- 用户注册（支持手机号和邮箱）
- 密码加密存储（SHA256）
- 用户登录验证

### 2. 座位选择
- 可视化座位图显示
- 实时座位状态（可用/已预订/已售出）
- 支持多座位选择
- 不同排次不同价格

### 3. 订单与支付
- 创建订单
- 多种支付方式（现金/支付宝/微信/银行卡）
- 订单查询
- 生成唯一票券码

### 4. 票券核销
- 票券验证
- 防止重复核销
- 核销时间记录
- 活动核销统计

## 数据库设计

### 用户表 (users)
- id: 用户ID
- username: 用户名（唯一）
- password: 密码（加密）
- phone: 手机号
- email: 邮箱
- created_at: 创建时间

### 活动表 (events)
- id: 活动ID
- name: 活动名称
- venue: 场馆
- event_date: 演出日期
- total_rows: 总排数
- seats_per_row: 每排座位数
- created_at: 创建时间

### 座位表 (seats)
- id: 座位ID
- event_id: 活动ID
- row_num: 排号
- seat_num: 座位号
- status: 状态（available/reserved/sold）
- price: 价格

### 订单表 (orders)
- id: 订单ID
- user_id: 用户ID
- event_id: 活动ID
- total_price: 总价
- status: 订单状态
- payment_status: 支付状态（paid/unpaid）
- created_at: 创建时间

### 票券表 (tickets)
- id: 票券ID
- order_id: 订单ID
- seat_id: 座位ID
- ticket_code: 票券码（唯一）
- verified: 是否已核销
- verified_at: 核销时间

## 使用流程

### 普通用户流程

1. **注册/登录**
   - 首次使用需要注册账号
   - 已有账号直接登录

2. **查看活动**
   - 浏览所有可用的演出活动
   - 查看活动详情（场馆、日期、票价等）

3. **选择座位**
   - 选择想要观看的活动
   - 查看可视化座位图
   - 选择心仪的座位（支持多选）

4. **下单支付**
   - 系统自动创建订单
   - 选择支付方式完成支付
   - 获得票券码

5. **入场验证**
   - 在活动当天出示票券码
   - 工作人员扫描核销

### 管理员流程

1. **核销票券**
   - 输入用户的票券码
   - 系统验证票券有效性
   - 完成核销并记录时间

## 技术特点

1. **安全性**
   - 密码SHA256加密
   - 唯一票券码防伪
   - 防止重复核销

2. **可靠性**
   - SQLite数据库持久化
   - 事务处理保证数据一致性
   - 完整的错误处理

3. **易用性**
   - 命令行交互界面
   - 可视化座位图
   - 清晰的操作提示

4. **可扩展性**
   - 模块化设计
   - 易于添加新功能
   - 支持多种支付方式
